
# Java IV — Festivali që përshtatet në çdo ekran

## Çfarë realizova
Ndërtova një faqe responsive për festivalin shkencor me gjashtë karta aktivitetesh, navigim fleksibël, imazhe lokale dhe lidhje drejt detajeve. Përdora HTML semantik, CSS të jashtëm, Flexbox, Grid, variabla dhe media queries.

## Struktura
- `index.html` — përmbajtja e faqes.
- `style.css` — stilet dhe përshtatja për ekrane të ndryshme.
- `assets/` — gjashtë ilustrime SVG lokale.

## Hapat e hapjes
1. Hap folderin `JavaIV` në VS Code.
2. Hape `index.html`.
3. Zgjidh **Open with Live Server**.
4. Për testim përdor DevTools → Toggle device toolbar.

## Reflektim individual: Kur do të zgjidhje Flexbox dhe kur Grid?
Do të zgjidhja Flexbox për rreshta ose kolona të vetme, si menuja. Do të zgjidhja Grid për organizimin dydimensional të kartave në disa kolona dhe rreshta.

## Deklarimi i AI dhe burimeve
Kam përdorur ndihmë nga AI për shpjegime dhe organizimin e HTML/CSS. Përmbajtja dhe aktivitetet janë shembuj mësimorë të sajuar. Ilustrimet SVG janë krijuar për këtë ushtrim.
