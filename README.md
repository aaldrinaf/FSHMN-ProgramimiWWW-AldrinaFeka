# programimi-www

## Përshkrimi

Ky repository përmban ushtrime dhe materiale nga lënda e Programimit Web. Projekti është i organizuar në folderat JavaI deri në JavaXIV.

## Hapja e projektit

Për të hapur faqen e parë të projektit, hapni:

`JavaI/index.html`

Faqja mund të hapet direkt në shfletues ose përmes një serveri lokal.
